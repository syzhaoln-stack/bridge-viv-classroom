先准备什么，再怎样使用

直接上课：先打开网页

解压后先双击总目录 index.html，再选一课进入。四套最终 HTML 已内嵌三维库、浏览端计算、样式和回放数据，可以本机离线运行。需要支持 WebGL 的现代 Edge 或 Chrome。涡振新增的实时 CFD 需本机 Python 求解服务；其余回放和课堂模型只需浏览器。

实时涡振：先在源码目录执行 python -m pip install -r viv/ale/requirements-live.txt 安装依赖，然后双击该目录的 启动实时涡振.cmd。浏览器会打开本机 8792 端口页面。点击“开始连续升速”，流体、网格与结构从当前状态持续求解。实时表示接受当前输入重新求解，运行速度取决于电脑；不保证与实际时间等速。停止服务后仍可使用回放环节。

如果三维没有出现，查看页内提示，确认浏览器图形加速可用。手机能操作旋转、缩放和滑块，但讲课、读图和修改程序建议用电脑。

要修改程序：提前准备软件

软件用来做什么何时需要
Edge / Chrome显示 WebGL、查看参数和图表运行网页
VS Code 或熟悉的代码编辑器打开源码文件夹，改 HTML/CSS/JavaScript修改程序
Python 3源码本地预览、把四课构建成独立 HTML修改后重新生成
Node.js LTS执行各课 physics-check.cjs 数值核验核对公式与计算
Python 的 NumPy；重算尾流另需 Numba重新处理六个原始涡振TXT，或重算新增低Re圆柱数值尾流仅重新计算数据时，播放不需要
Python 的 NumPy、SciPy、scikit-fem、meshpy实时局部动网格流固耦合涡振实时页运行时需要

官方下载：Python、Node.js、VS Code。本次构建使用 Python 3.13.5、Node.js 22.19.0。常规构建只使用标准库，不需要 npm install；这次也未复制 node_modules 和大型三维模型缓存。

安装后重新打开终端，输入 python --version 与 node --version 检查命令。Windows 如果只有 py 命令，可将 python 替换成 py -3。

文件要怎样准备

1. 完整解压 ZIP，不要在压缩软件内部预览运行。

2. 保留四个展示 HTML 和目录页。它们彼此可以直接导航。

3. 源码在“源码”文件夹；若只传一个课程的 src 给别人，还要保留共用 shared、vendor 和构建工具。

4. 修改前复制一份练习目录，先改文字或颜色，确认能重建，再改公式、参数或三维场景。

原始 wolai 页面提供 MATLAB Live Script 与原始记录，来源、文件名和迁移纠错见每课“原代码核对”。本包提供已使用的 MATLAB 提取文本、源文件哈希和经过处理的六工况数据，不重复塞入大量原始附件。

修改的顺序

先读各课 README，再看 physics.js 的单位、方程和输入输出。app.js 连接控制、三维场景与图表；index.html、style.css 控制页面；shared/stage.js 是相机、光照和轨道操作；shared/lab.js 是图表和 CSV。

在解压包的总目录，执行以下命令可预览可编辑源码：

python -m http.server 8791 --bind 127.0.0.1 --directory 源码

然后打开 http://127.0.0.1:8791/index.html。终端窗口保持打开，结束按 Ctrl+C。

在解压包总目录执行以下命令，把改过的源码重新生成到当前展示目录：

python 源码/build.py --output-dir .

再刷新或重新打开对应 HTML。构建会覆盖生成的 HTML，所以应先改源码，而不是只改成品网页。

修改后怎样检查

在总目录分别执行：

node 源码/cfd/physics-check.cjs
node 源码/cfd/derivative-check.cjs
node 源码/buffeting/physics-check.cjs
node 源码/buffeting/mechanism-check.cjs
node 源码/buffeting/response-check.cjs
node 源码/buffeting/spectrum-check.cjs
node 源码/viv/physics-check.cjs
node 源码/design/physics-check.cjs

再逐页操作：改变一个参数、拖动时间、旋转缩放、下载 CSV，确认计算与图形变化一致。检查单位、正负号、边界条件、谱积分与输入数据窗口。最后断开外网，用独立 HTML 再运行一次。

四课的模型边界

- CFD：先用同一个解析标量场解释空间二阶导数与时间差分，再接原课一维守恒传输问题；桥梁外流场流程不冒充高雷诺数三维数值解。

- 抖振：大涡小涡用归一化均匀桥宽积分解释抵消，不能代替试验导纳。随机教学风场与简化单模态结构同相位连接风—荷载—响应；局部导纳和跨向相干分别处理。

- 涡振：新增低Re固定圆柱二维数值尾流、原始六工况记录、可调教学振动模型分别标注。新增尾流与旧记录不是同一工况；频率交会不直接等于求得锁定区。

- 抗风设计：装置构造与力学反馈、断面形状、设计证据链分别展示。项目系数、临界风速、限值和工况需工程依据；形状变化不自动获得某个气动改善百分数。
