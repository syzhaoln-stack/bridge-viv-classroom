# 涡振 · 手机交互课堂

[打开涡振实验](https://syzhaoln-stack.github.io/bridge-viv-classroom/)

运行中拖动风速，观察尾涡与结构位移。常用结构参数为固有频率和阻尼比；质量、Scruton 数、固定切换、压力和导出放在“更多观察与设置”。

末尾设四道课堂题，分别对应涡振特征、颤振与其它风致效应、脱涡与升力频率、减振措施。学生可调用同一实验观察、记录真实窗口读数，再选择答案并查看反馈；不需要登录或上传个人信息。

`index.html` 是轻量独立网页，Worker 求解器也已内嵌，可直接离线打开或托管于 GitHub Pages。每个浏览器独立计算，无服务端接口，也不读预计算流场来替代计算。详细分析和既有回放只在用户进入进阶页时加载。

浏览器版采用二维低雷诺数圆柱 D2Q9/BGK 与结构双向耦合，CFD 动量交换升力驱动结构，结构运动反馈流体。使用附体坐标和横向周期边界；这不是局部 ALE 动网格。主图转换到实验室视图并显示真实位移比例；结构示意的倍率另标。

教师进阶页保留原固定外边界、局部网格变形的 ALE 分析和回放。本机实时 ALE 需要 Python 服务；其余离线回放可从此站打开。本模型用于课堂观察，不用于桥梁工程响应量值预测。

## 修改与构建

可编辑手机源码在 `src/`。修改 `browser-panel.html`、CSS、视图或计算核心后执行 `python build.py`；不需要安装 npm 包。提交根目录生成的 `index.html` 与修改过的源文件即可更新首页。进阶分析是独立保留的构建产物，不参与手机首屏加载。

## 验证

浏览器求解器的原 Python 移植对照、结构自由振动和阻尼检查、连续风速与阻尼分支、手机交互及离线运行检查见 `verification/`。有限网格教学检查不等同于工程网格收敛。
