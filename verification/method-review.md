# 浏览器轻量 CFD：独立数值检查范围

这一页记录浏览器版的检查原则；实际通过与否以同目录带源代码 SHA-256 的运行报告为准。

## 方法和坐标

轻量版移植原有二维 D2Q9/BGK 流固耦合，在圆柱附体坐标中计算。横向边界周期配对，实验室坐标中的整个计算域随圆柱平移；这不是外边界固定的局部 ALE 动网格。原局部 ALE 页面作为另一种进阶计算保留。主屏必须准确说明两种方法，不能把随体格线画成经过求解的局部变形网格。

圆柱相对流体速度为壁面零速度，远处相对横速为 −v_body，惯性源为 −a_body。碰撞后的速度恢复与碰撞前 Guo 力项使用不同半步约定；移植中若漏掉源项变更的一阶矩修正，会造成非物理脉冲。[Guo、Zheng 与 Shi 的原论文](https://doi.org/10.1103/PhysRevE.65.046308)阐述在 LBM 中正确引入力项的重要性；这里仍需通过生产代码数值对照验证具体时间层实现。

## 单位和控制量

风速、时间、频率应始终使用同一组固定参考量。风速 U 改变时不能同时改变时间标度，使用户设置的结构固有频率暗中变化。

```text
Re = U D / nu
Ur = U / (fn D)
m* = m / (rho pi D^2 / 4)
k = m (2 pi fn)^2
c = 2 zeta m (2 pi fn)
Sc = 4 pi m zeta / (rho D^2) = pi^2 m* zeta
```

保持同一运动黏度时，连续升风速也会提高 Re。设置 fn 或 m* 应更新 k、c，设置 Sc 应在当前 m* 下换算 ζ；这些操作保留已有流场和结构状态。切换固定时约束当前位移、令结构速度为零；这是施加约束，会改变动量，不应把结构瞬移到初始位置。释放约束后从当前状态推进。

## 观测频率和有限窗口

固定圆柱脱涡的 Strouhal 数定义为 St = fs D/U；它是结果的无量纲表达，不是应给升力硬编码的激励函数。[NASA 圆柱验证案例](https://www.grc.nasa.gov/www/wind/valid/lamcyl/Study1_files/Study1.html)采用低 Re = 150 的二维周期脱涡，并说明用升力或偏离尾迹中线的探针识别脱涡频率。阻力以及中线纵向速度可能主要含两倍脱涡频率，因此不能直接取其主峰作为 fs。

实际测频应报告信号、真实窗口长度、采样间隔和频率分辨率。扫速过程的频谱属于有限时间变化信号，窗口必须短到能追踪变化、长到含多个周期；两者存在取舍。不能把 St U/D 的参考估算冒充 CFD 测得频率，也不能以 fn 强制裁剪频谱峰值。

## 检查计划和限制

1. 检查参数换算、连续更新不重置、固定/释放不瞬移；与原 Python 短程流场/受力对照以防移植错误。
2. 隔离实际生产结构积分器，检查零力自由振动和阻尼衰减；验证固有频率、阻尼与输入相符。
3. 同一流场连续低—近—高风速，记录真实载荷、位移、密度和局部 Mach 数；不预设必须出现振幅峰。
4. 从同一成熟状态分支，改变 ζ，记录真实响应差异；不人工缩放升力或位移。

隐式中点结构推进降低了后向 Euler 的算法阻尼，但流固耦合仍是旧气动力保持一步的显式分区法。粗网格、半格反弹、有限周期域、低马赫近似及流固时间滞后都可能影响频率和幅值；课堂演示不能据此作桥梁工程精度或锁定区边界结论。
